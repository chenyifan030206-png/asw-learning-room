# D18 内容设计、前置知识与验收
依据84天路线第18天：概率与低通滤波，固定随机种子噪声、一阶滤波、alpha=.1/.8、原始/滤后方差和阶跃上升时间。D17在线通过，反馈仅有“误差和噪声的关系”，不推定其他知识未掌握。
教学依赖：测量值=真值+偏差+噪声（区别D17离散误差）→概率与理想均匀分布→固定种子与控制变量→样本均值/方差/标准差→MSE与偏差→加权平均和一阶递推→单位阶跃与10%-90%上升时间→白噪声稳态方差推导→API独立例子→源码与测试。D19卡尔曼滤波不提前。
统计用ddof=0及索引50至249；阶跃实验单独无噪声、dt=.1，索引20起0→1，首样本为相对时间0。alpha=.1/.8共享输入；预计rise=2.1/.1s。种子18用教学线性同余递推，非真实传感器模型。方差理论比例alpha/(2-alpha)只在独立零均值噪声、恒定真值、稳态成立。
