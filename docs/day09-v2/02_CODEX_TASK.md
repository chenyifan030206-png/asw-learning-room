## C. 页面UI与交互的工程实现要求

### C1. 信息层级与首屏

- 学习入口上方不要永久占用大块云同步说明。保留原来的云同步能力，但以可展开区域或右上入口呈现；不要默认展示大段token申请教程。
- 学课程页面第一个视觉区块为“场景目标 + 三输入参数 + 0/10/20/30/40/50/60时间轴 + 两个结果”。
- 紧接“代码结构/符号来源”可导航的表；列表项标签短，详细解释按需展开。
- 阅读内容不再是几十段独立横跨全屏的纯文字块；例子、源码、算式和预期输出在视觉上相邻。

### C2. 同步代码与解释

- 桌面 >=1100px：源码面板约55-60%，解释约40-45%，独立滚动，源码行号可复制，右侧说明同步当前step。
- 选中某步：自动选择正确文件、定位行并高亮；“查看定义/返回调用处”按钮可在 `demo.c`、`timing.h`、`timing.c` 间跳转。
- 手机上（<=768px）：单列显示，提供明确的“看源码/看解释”切换，记住已选步骤和文件；不能通过横向滚动整页才能读说明。
- `app.js showStep()` 当前使用 `source.indexOf(s.start)` / `indexOf(s.end)` 抽取。**D09新步骤改为结构化定位** `{file,start_line,end_line,focus_line,origin_symbol,...}` 或可靠的唯一代码标识；保留旧D01–D08的数据兼容分支，不要因一次CSS/注释变化截到错误代码。
- 长源码保持完整可展开并可下载，不得只保留片段；按执行步骤高亮源码，而不是仅再次复制另一份代码。
- 保留已实现的文本划线/颜色/批注/编辑个人源码与云同步。若课程改版导致旧定位无法命中，不应静默丢弃旧批注；做兼容索引或显式“需要复核”提示。

### C3. 时间轴和逐轮变量可视化

提供唯一一个主要交互图，数据来自确定性教学模拟结果（或同一规范函数），不能只画装饰箭头：

- 输入：速度、跳过轮次、迟到毫秒。
- 每行：tick、计划时刻、是否跳过、实际时刻、写入下标、last执行前、dt(ms)、本段固定/实际位移、累计位移。
- `tick=3` 设置skip时必须展示“continue，不更新last/control_count”，下一轮显示20ms差。
- 选中某行显示关联C代码片段和变量变化。提供“上一步、下一步、重置”，键盘可操作。
- 主课常驻精简比较：“固定10ms累计 / 按实际dt累计”；失败时不显示有效结果。
- 小屏必须保证时间表易读，可按时刻逐张卡片显示，不可把9列小字压成同一行。

### C4. 学习任务与反馈

- 主课必做推荐四场景（正常/漏30ms/迟到5ms/非法速度），另外可选漏50ms、速度20m/s迁移。原7项主课可保留可点，但不要逼初学者七项刷完才能读懂主线。
- 每个场景流程：先预测（不展示答案）→运行 →显示计算解释→独立反推/复述。预测/真实结果应在同一视觉区域。
- D09测验至少包括“变量来源定位”“同名成员属于哪个对象”“&result与*out关系”“20ms的由来”“漏控制≠安全保证”。按错题回到对应代码步骤，而非泛泛提示“回答错误”。
- 让用户直接选源码文字写中文注释、颜色标记，保留目前的浏览器自动保存与私有云同步流程。

## F. 需真实执行的验收测试

### F1. 本地C编译 / 执行

在真实下载出的D09主课工程目录：

~~~bash
gcc -std=c17 -Wall -Wextra -Wpedantic -Wconversion -Werror demo.c timing.c -o timeline_demo -lm
printf '10 -1 0\n' | ./timeline_demo
printf '10 3 0\n' | ./timeline_demo
printf '10 -1 5\n' | ./timeline_demo
printf '%s\n' '-1 -1 0' | ./timeline_demo
~~~

验收断言：
1. 正常：control=0,10,20,30,40,50,60，dt=0,10,10,10,10,10,10，fixed≈0.6，measured≈0.6。
2. 漏30：control=0,10,20,40,50,60，dt=0,10,10,20,10,10，fixed≈0.5，measured≈0.6。
3. 迟到：control=0,10,20,35,40,50,60，dt=0,10,10,15,5,10,10，fixed≈0.6，measured≈0.6。
4. 非法速度：status=-2，不将输出作为有效数据。
5. 检查 `skip_tick=3,late_ms=5`：被跳过的30ms轮次仍不记录35ms更新。
