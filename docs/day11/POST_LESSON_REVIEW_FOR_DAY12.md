# D11 学习反馈与 D12 教学调整

依据：D11 学员明确报告“浏览器练习通过；不是本地真实 C 通关”，并反馈源码注释不足、不清楚什么时候用 `*`、`->`、`.`。批注还暴露出 `(tail+1)%4` 被理解为“四进制”，`volatile` 定义不清晰，以及需要重新解释 `head/tail/count` 的声明位置。

## 先纠正三个具体概念

1. **`%4` 是整数取余，不是四进制。** 4格数组，`(3+1)%4=0`，是把写入下标从3回绕到0；这与数字的二进制、十进制、四进制表示没有关系。
2. **`head/tail/count` 是结构体成员。** 在 `sensor_queue.h` 的 `FrameQueue` 类型中声明；`demo.c` 创建 `FrameQueue queue={0}` 时，对象自动拥有这些成员。**`#define QUEUE_CAPACITY 4u` 是预处理宏定义，不是这三个成员的声明**。
3. **`volatile` 不是“定义/define”的意思。** 它是类型限定符，涉及某些对象访问的可观察性；自身不提供线程互斥、原子操作、数据竞争保护或一致快照。

## D12 的语法学习规则（不能省略）

| 写法 | 首先确认什么类型 | 解释与相邻例子 |
|---|---|---|
| `sample.distance_m` | `sample` 是结构体对象 | 点号表示取对象成员 |
| `step->read_fail` | `step` 是结构体指针 | 箭头表示通过指针访问成员；等价`(*step).read_fail` |
| `VehicleIf_Read(&sample)` | `sample` 是真实对象 | `&`取地址，使Read能把值写入 |
| `VehicleSnapshot *out` | 位于声明中 | `*` 声明指针变量 |
| `*out = step->frame;` | `out` 已声明为指针 | `*` 解引用：给指向的整个结构体对象赋值 |
| `speed * dt` | 两侧都是算术值 | 此处星号才表示乘法 |

**必须在每个文件新符号第一次出现处，注明类型、定义文件、读写谁、数据来自哪里。** 不用“接待员/账本”代替真实 C 对象。

## D12 基础任务和边界

根据课程总路线，D12应为“ASW、RTE与车辆接口”，而不是再次叠加新的复杂状态机。主课聚焦三轮模拟输入：应用调用VehicleIf_Read取得一份完整数据→通过对象点号读取成员→根据教学阈值计算输出→调用VehicleIf_Write发布。接口的模拟实现放另一.c；不能声称这是真实 AUTOSAR RTE/ECU/CAN。再安排读取失败、输入无效、写失败的独立场景，要求区分应用返回码、输出valid以及本次是否成功发布。
