# Python 零基础精讲 V4：公开教材复核与 ASW 学习顺序审计（2026-11-10）

## 学习者反馈及准确定位

反馈：学习者已完成一部分 C 语言基础，但此前没有系统学过 Python，不理解下划线 `_`、点号 `.`、括号、缩进、`for`、`while` 和 `enumerate`。旧版教程过早使用 ASW 完整多文件工程，且循环被拆散，在尚未解释 `for` 的时候使用了 `enumerate`。

仓库现状审计（V3原文件）：23 章、144 个小节；`v2_08` 有 9 个循环小节，`v3_iteration_tools` 另外放了 8 个 range/enumerate/zip 主题。144 个小节中有 **129 个 `parts` 语法拆解表为空**，造成“看完说明还是不知道符号具体做什么”。旧书、旧笔记和源代码实作不应因此覆盖。

## 从公开 GitHub 教材吸收的教学逻辑

### 1. 骆昊 Python-100-Days

仓库：https://github.com/jackfrued/Python-100-Days

参考的是实际 README 的初学教学章节顺序：
Day01 环境、Day02 第一个脚本和注释、Day03 变量与类型、Day04 运算符、Day05 分支、Day06 **在同一章讲 `for` 与 `while`**、Day08–09 列表、Day14 函数与模块。说明先用独立控制流案例练习，容器与工程模块随后加入。

我们的改动：第02章先建立标点认知；第08章统一 `for/while/range/enumerate/zip`，第09章留给多帧应用巩固。

### 2. trekhleb/learn-python

仓库：https://github.com/trekhleb/learn-python

项目README把教材定位为练习场与速查表，典型主题文件具备解释、可执行 Python 示例和 `assert`，并鼓励改动源码验证结果。

我们的改动：每个小节保留最小示例、逐步推演、可核对预期值、错误写法、个人修改练习；另外增加 for/while/enumerate/zip **四张逐轮变量表**。真实 Python 运行与网页阅读/模拟分开。

### 3. 李金 notes-python

仓库：https://github.com/lijin-THU/notes-python

目录把字符串、索引/切片、列表、赋值机制、分支、循环、函数、模块、异常、文件分别分章。注意该笔记 README 指定 Python 2.7，已有版本跨度与内容使用权的说明；这里只借鉴“概念细拆、索引独立、赋值单讲”的组织思想，不复制源代码，也不向学习者推荐 Python 2.7 环境。

我们的改动：标点字典单章；把 `_`、`.`、`:`、`()[]{}` 作为可查字典，在各个后续章节再次说明上下文，避免“一次定义用途从此都一样”的误解。

### 4. Microsoft c9-python-getting-started

仓库：https://github.com/microsoft/c9-python-getting-started

README说明系列适合“已有少量其他语言基础”的学习者，逐步包含语法、类、文件和包使用。它不是一份默认能读懂任意 Python 代码的零基础语法词典；因此我们仅用于C/Python概念对照，不跳过Python符号本身的解释。

## 修改后体系

- 第01–03章：程序如何运行、32个符号的可查字典、环境/工作目录。
- 第04–07章：变量与类型、运算符、字符串、if/elif/else。
- 第08章：**一次讲透全部循环相关语法**，17个详细小节；四张逐轮执行表，说明每轮取得的值、条件判断、输出和退出。
- 第09章：原8个工具语法专题保留（已迁到08整合），新章仍可独立复习；按ASW场景巩固帧号、下标和信号配对。章节ID不变，个人旧笔记不会被重新关联到不同ID。
- 第10–12章：list/dict/tuple/set、推导式。
- 第13–16章：def、return、参数、模块import、class/dataclass。
- 第17–23章：文件CSV/JSON、异常、单元测试、ASW多文件完整执行链、故障注入、查阅、衔接NumPy。

质量口径：**23章、156个详细专题、32种符号解释，所有专题至少3条语法拆解和3步执行路径。** 旧版v3完整保留，原D15的进度及用户本地 C/Python 验收保持不变。

## 线上与真实执行边界

- 浏览器上的“逐轮表”是教材推演，不是页面执行的Python程序。
- GitHub Actions从参考工程实际运行Python单元测试，并运行V4示例脚本：156个均做Python语法解析，138个在标准Python环境执行，131个核对精确输出；18个包含交互、外部文件或特殊执行环境，按类别例外处理。
- 独立导学页的自动保存仍使用既有localStorage记录键 `asw-python-foundation-v1:`，保留章节ID、个人批注与笔记导入/导出功能；未触及原D15私有记录库。
- 学员要在本地真正运行、预测、故障注入、修复测试后，才能记为自己的真实通关。
